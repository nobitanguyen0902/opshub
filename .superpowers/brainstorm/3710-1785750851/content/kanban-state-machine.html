Resume và idempotency

  • Mỗi lệnh create stage có idempotency key theo logical task + stage + attempt.
  • Khi mở lại app, OpsHub đối chiếu workflow index với `hermes kanban show/runs --json` rồi tiếp tục từ transition chưa hoàn tất.
  • Nếu reclaim thành công nhưng block thất bại, card vào Needs Attention và hiển thị thao tác recovery; không báo Cancel thành công sai.

Xác nhận state machine này trong Codex hoặc nêu nhánh bạn muốn đổi.
