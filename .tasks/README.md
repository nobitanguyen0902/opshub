# Task Workflow

Mỗi task được lưu trong một thư mục riêng:

.tasks/YYYYMMDD-task-name/

Luồng xử lý:

1. Architect tạo:
   - architect.md
   - handoff-developer.md

2. Developer thực hiện code và tạo:
   - implementation.md
   - handoff-reviewer.md

3. Reviewer kiểm tra và tạo:
   - review-report.md

Không sử dụng cùng một chat session giữa các profile.
Mỗi profile phải đọc file handoff của bước trước.
